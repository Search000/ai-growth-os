# AI Growth OS

Private local-first AI Growth OS. Runs on personal PC using local LLM (Ollama + Llama 3.1 8B) - no third-party AI API dependency.

## Status
Phase 0 - Foundation setup in progress.

## Hardware
- CPU: Intel i3-10105 (4c/8t)
- RAM: 16GB
- GPU: None (CPU inference)
- Model: Llama 3.1 8B Instruct Q4_K_M via Ollama
- Model storage: F:\AI_Growth_OS\OllamaModels
